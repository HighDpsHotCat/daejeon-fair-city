# 공정도시 대전

대전광역시 정부대전청사와 주변 도심을 배경으로 한 조달 업무 조사 게임의 최종 실행 산출물입니다.

**[최종 실행본 및 시연 영상 다운로드](https://github.com/HighDpsHotCat/daejeon-fair-city/releases/tag/final-2026-11-18)**

이 저장소는 실행 산출물 배포용입니다. 대용량 게임 데이터는 **Releases의 첨부 파일**에 포함되어 있습니다. GitHub의 `Code → Download ZIP` 또는 자동 생성된 `Source code` 파일에는 전체 게임 데이터가 없으므로, 위 실행본 ZIP을 받으세요. Unity 편집용 원본 프로젝트는 포함하지 않습니다.

## 웹 버전 실행 — 권장

1. 웹 실행본 ZIP을 다운로드하고 압축을 모두 풉니다.
2. Python 3.9 이상이 설치된 Windows에서는 `웹 게임 실행.cmd`를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:8765/`가 열립니다. 서버 창을 닫으면 게임 서버가 종료됩니다.

다른 운영체제에서는 압축을 푼 폴더에서 `python3 web_game.py`를 실행할 수 있습니다. WebGL 2를 지원하는 최신 PC 브라우저를 사용하세요.

Python 없이 실행하려면 `Web/index.html`을 브라우저에서 열고 **게임 데이터 폴더 선택**을 눌러 같은 폴더의 `Web/Build`를 선택하세요. 이 방식에는 폴더 선택과 gzip 압축 해제를 지원하는 최신 브라우저가 필요합니다. 실행되지 않으면 위 로컬 서버 방식을 사용하세요.

웹 버전은 조사 단계와 완료한 업무 진행도를 브라우저에 자동 저장합니다. 화면 아래의 **진행도 초기화**로 기록을 지울 수 있습니다.

## Windows 버전 실행

Windows 실행본 ZIP을 모두 푼 다음 `공정도시 대전.exe`를 실행합니다. 같은 폴더의 `공정도시 대전_Data`, `MonoBleedingEdge`, DLL 파일은 함께 보관해야 합니다.

## 기본 조작

| 입력 | 동작 |

## 웹 서버 배포 참고

`.unityweb` 파일은 gzip으로 압축되어 있습니다. 별도 웹 서버에 배포한다면 `Content-Encoding: gzip`과 원래 파일 형식에 맞는 MIME 유형을 제공해야 합니다. 포함된 `web_game.py`는 로컬 실행을 위한 헤더를 처리합니다. 저장소를 업로드하는 것만으로 온라인 플레이 주소가 생성되지는 않습니다.

나눔 폰트 라이선스는 [`Web/FontLicense.txt`](Web/FontLicense.txt)에 포함되어 있습니다.
